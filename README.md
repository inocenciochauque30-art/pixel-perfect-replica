# Mangueiras Restaurante e Bar

Menu digital de consulta por QR Code, sem pedidos, carrinho, conta ou autenticação.

## Publicação

O site é estático e pode ser publicado com GitHub Pages a partir da branch `main`, pasta `/ (root)`.

## Conteúdo

Menu de comidas e bebidas em Meticais (MT), com pesquisa e navegação adaptada a telemóveis.

Nota: o preço de Drosty não foi indicado no conteúdo recebido; aparece como “Consultar” para não inventar um valor.
