# Mangueiras Restaurante e Bar

Menu digital estático de consulta por QR Code. Este projeto serve exclusivamente para consultar comidas, bebidas e preços em Meticais (MT).

## Conteúdo atual

- **Comidas:** 9 categorias e 39 itens.
- **Bebidas:** 11 categorias e 70 itens.
- **Total:** 20 categorias e 109 itens.
- Navegação por separadores COMIDAS e BEBIDAS.
- Pesquisa por nome, categoria e preço, sem distinção entre maiúsculas/minúsculas ou acentos.
- Galeria com três imagens ilustrativas, sem associação a pratos específicos.
- **Drosty-Hof:** 650 MT.
- Os preços indicados como **Consultar** ou **Por KG** foram mantidos assim; nenhum preço foi inventado.

## Funcionalidades e limites

Este é apenas um menu de consulta. Não inclui carrinho, pedidos, pagamentos, contas, login, registo, painel administrativo, backend ou base de dados.

## Publicação

A publicação ainda depende da configuração e ativação do serviço de alojamento escolhido. Se for usado GitHub Pages, selecionar a branch `main` e a pasta raiz `/ (root)` nas definições do repositório. A existência deste ficheiro não significa que o site já esteja publicado.
